# Privacy Statement

StatementDesk v0.1 is a **local-first** application.

## What we collect

**Nothing.** There are no accounts, no telemetry, no analytics, no crash reporting and no network activity during import, reconciliation, review or export. The application makes no outbound connections while you use it.

## Where your data lives

- **Projects** are stored as local **SQLite** files at a location you choose.
- **Exports** (XLSX / CSV / HTML) are written to a location you choose through a native save dialog.
- **Feedback and diagnostics** are written to a local file only if you explicitly save them; they are never transmitted. Diagnostics contain only app version, OS version, row counts and error codes — no customer data.

## Encryption — important limitation

In v0.1, local project files and exports are **not encrypted at rest**. Protect them using your operating system's disk encryption (FileVault on macOS, BitLocker on Windows) and normal file permissions. Treat exported statements and ledgers as sensitive financial data.

## Data retention

You are in full control. Deleting a project file removes its data. Uninstalling the application does **not** delete your project files.

## Third parties

No data is shared with any third party, because no data ever leaves your computer.
